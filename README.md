# 📦 Portofolio Project — School Project

>Aplikasi web peminjaman barang yang dikembangkan sebagai bagian dari proyek pembelajaran di sekolah. Project ini dibuat untuk mengeksplorasi pengembangan web.

## 🎯 About The Project

Project ini merupakan salah satu latihan dalam proses belajar pemrograman web. Tujuannya adalah memahami bagaimana membangun web sederhana yang memiliki struktur halaman untuk kebutuhan portofolio.

Project ini juga menjadi bagian dari dokumentasi perjalanan belajar dan pengembangan portofolio pribadi di bidang pemrograman.

## ✨ Features

- pages utama
- profil
- About me

- My project
